# DeepPhotoRestore: Восстановление изображений с CFA‑сенсоров

Проект реализует полный конвейер для повышения качества изображений, получаемых малогабаритными сенсорами с мозаикой Байера (RGGB).  
**Основная задача:** преобразование шумного, размытого RAW‑сигнала (упакованного в 4 субканала) в резкое полноцветное RGB‑изображение с увеличением разрешения в 2 раза.

**Ключевые особенности:**
- Физически достоверная генерация синтетического датасета (PSF, маска Байера, коррелированный шум).
- Архитектура NAFNet + PixelShuffle, обученная с комбинированной потерей L1 + Focal Frequency Loss.
- Валидация с расчётом PSNR/SSIM и визуализацией восстановленных изображений.
- Сравнение с классическими алгоритмами демозаики (билинейная, Malvar‑He‑Cutler).
- Конфигурируемый графопостроитель для диссертационных иллюстраций.
- Обработка видео (покадровая деградация + восстановление).

---

## Быстрый старт

```bash
# 1. Установка окружения (см. INSTALL.md)
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt

# 2. Генерация датасета (если ещё нет)
./run_pipeline.py -opt options/train/your_config.yml --clean-dataset

# 3. Обучение модели
./run_training.py -opt options/train/your_config.yml --clean-training

# 4. Построение графиков
./plot_metrics.py -opt options/plot/plot_config.yml

# 5. Оценка baseline (билинейная, MHC)
./evaluate_baseline.py -opt options/train/your_config.yml

# 6. Инференс на видео (опционально)
./process_video.py -opt options/video/process_video.yml --input video.mp4 --output restored.mp4
```

## Требования

- Python 3.12
- NVIDIA GPU с драйверами CUDA 12.x (рекомендуется) – 12 ГБ VRAM
- Остальные зависимости – в `requirements.txt` (устанавливаются автоматически)

Подробная инструкция по установке – в [INSTALL.md](INSTALL.md).

## Структура проекта

```
DeepPhotoRestore/
├── run_pipeline.py          # предобученческий конвейер
├── run_training.py          # обучение нейросети
├── plot_metrics.py          # построение графиков
├── evaluate_baseline.py     # сравнение с классическими методами
├── process_video.py         # обработка видео
├── libraries/               # все модули (pipeline_, training_, общие)
├── options/                 # YAML‑конфигурации (train, plot, video)
├── experiments/             # результаты экспериментов (логи, чекпоинты, графики)
├── datasets/                # сгенерированный датасет (train/test)
├── samples/                 # временные визуализации (если не перенаправлены)
└── docs/                    # вся документация (файлы .md)
```
