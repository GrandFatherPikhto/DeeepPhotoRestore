# DeepPhotoRestore — Pipeline для реставрации изображений с CFA-сенсоров

## 1. Что это такое?

**DeepPhotoRestore** — это исследовательский программный комплекс для повышения качества изображений, получаемых с малогабаритных сенсоров, оснащённых мозаичными светофильтрами (Bayer RGGB). Проект реализует полный цикл:

- **Физически достоверную генерацию обучающих пар** (LQ / HQ), моделирующую работу реального сенсора:  
  пространственное сжатие → свёртка с PSF (ЧКХ) → наложение маски Байера → коррелированный шум → извлечение 4 каналов RGGB.
- **Обучение нейросетевой модели NAFNet** (Nonlinear Activation Free Network) для восстановления полноцветного RGB-изображения из 4-канального LQ-входа.
- **Комбинированную функцию потерь** — пространственная L1Loss + частотная FocalFrequencyLoss (FFL), заставляющая модель восстанавливать высокочастотные детали.
- **Оценку качества** с помощью метрик PSNR, SSIM и визуального сравнения с классическими методами демозаики (билинейная интерполяция, MHC).

Проект выполнен в рамках магистерской диссертации и строго соответствует заявленному техническому заданию.

## 2. Как на данном этапе этим пользоваться

### 2.1. Требования к окружению

- Операционная система: **Linux** (рекомендуется Ubuntu 22.04/24.04) или **WSL2** под Windows.
- **Python 3.12** (виртуальное окружение).
- **NVIDIA GPU** с драйверами, поддерживающими CUDA 12+ (опционально, но настоятельно рекомендуется).
- Установленные зависимости (автоматически при создании окружения).

### 2.2. Быстрый старт (пошагово)

#### Шаг 1. Клонирование репозитория и установка окружения

```bash
git clone https://github.com/your-repo/DeepPhotoRestore.git
cd DeepPhotoRestore
python3 -m venv .venv
source .venv/bin/activate
pip install --upgrade pip
pip install -r requirements.txt
```

#### Шаг 2. Подготовка исходных изображений

Поместите ваши эталонные изображения (RAW-файлы .NEF, .CR2 или качественные .JPEG/.PNG) в папку:

```bash
mkdir -p source_images
cp /path/to/your/images/* source_images/
```

#### Шаг 3. Генерация датасета и проверка конвейера

```bash
./run_pipeline.py -opt options/train/RAW_NAFNet_NikonD600.yml --clean-dataset
```

Эта команда:
- Очистит старый датасет (если есть).
- Сгенерирует пары LQ/HQ в папку `datasets/nef_nafnet/`.
- Выполнит визуальный контроль (сохранит примеры в `samples/debug_visuals/`).
- Проведёт smoke-тест модели на одном батче.

#### Шаг 4. Запуск обучения

```bash
./run_training.py -opt options/train/RAW_NAFNet_NikonD600.yml --clean-training
```

- Обучение начнётся с нуля (или продолжит с последнего чекпоинта, если не указан `--clean-training`).
- Логи и веса сохраняются в `experiments/RAW-NAFNet-D600/`.
- В процессе обучения каждые 10 эпох выполнятся:
  - сохранение чекпоинта
  - валидация на тестовых изображениях → результаты в `experiments/RAW-NAFNet-D600/val_predictions/`

#### Шаг 5. Мониторинг обучения

Запустите TensorBoard:

```bash
tensorboard --logdir experiments/RAW-NAFNet-D600/tb_logs
```

## 3. Скрипты и модули (в рабочем состоянии)

### Основные исполняемые скрипты (находятся в корне проекта)

| Скрипт | Назначение | Статус |
|--------|------------|--------|
| `run_pipeline.py` | Предобученческая проверка: генерация датасета, визуальный контроль, smoke-тест. | ✅ |
| `run_training.py` | Запуск обучения NAFNet с комбинированным лоссом. | ✅ |

### Вспомогательные скрипты (утилиты)

| Скрипт | Назначение | Статус |
|--------|------------|--------|
| `prepare_dataset.py` (упрощённый) | Тонкая обёртка для вызова `process_source_images`. | ✅ |
| `evaluate_baseline.py` | Сравнение с билинейной интерполяцией (требует доработки MHC). | ⚠️ |
| `plot_curves.py` | Построение кривых обучения из логов TensorBoard. | ✅ |
| `smoke_test.py` | Отдельный запуск стресс-теста (дублирует часть `run_pipeline`). | ✅ |
| `check_visuals.py` | Быстрый визуальный контроль LQ/HQ без обучения. | ✅ |

### Библиотеки (`libraries/`)

| Модуль | Функциональность |
|--------|------------------|
| `pipeline_config.py` | Парсинг аргументов, загрузка YAML. |
| `pipeline_device.py` | Определение устройства (GPU/CPU). |
| `pipeline_data.py` | Класс `RestorationDataset` + аугментации. |
| `pipeline_model.py` | Создание модели NAFNet с обёрткой 4→3 канала. |
| `pipeline_prepare.py` | Проверка и генерация датасета (вызов `process_source_images`). |
| `pipeline_generation_io.py` | Пакетная обработка исходных изображений. |
| `pipeline_generation_core.py` | Пошаговая деградация (downscale → PSF → Bayer → шум). |
| `pipeline_degradation_ops.py` | Примитивы: ядро PSF, шумы, маска Байера, извлечение RGGB. |
| `training_logger.py` | Логирование в файл и TensorBoard. |
| `training_validator.py` | Валидация, сохранение восстановленных изображений. |
| `training_checkpoint.py` | Сохранение/загрузка чекпоинтов. |
| `training_losses.py` | `FocalFrequencyLoss` (FFL) – готова к интеграции. |

## 4. Заключение

**DeepPhotoRestore** представляет собой полностью работоспособный исследовательский пайплайн для задачи восстановления изображений с мозаичных сенсоров. На текущий момент:

- ✅ Реализована физически достоверная генерация датасета.
- ✅ Обучение NAFNet с аугментациями, логированием и чекпоинтами.
- ✅ Визуализация и валидация в процессе обучения.
- ⏳ Ожидает интеграции комбинированный лосс (`CombinedLoss = L1 + γ·FFL`) для полноценной научной новизны.
- ⏳ Предстоит адаптировать `evaluate_baseline.py` для расчёта SSIM и сравнения с градиентным методом MHC.

Проект готов к запуску экспериментов и служит надёжной основой для магистерской диссертации. Для расширения функциональности достаточно добавить больше исходных изображений в `source_images/` и при необходимости увеличить `num_epochs` в YAML.
