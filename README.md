# DeepPhotoRestore: Восстановление изображений с CFA-сенсоров

Этот проект реализует полный конвейер для повышения качества изображений, получаемых малогабаритными сенсорами с мозаичными светофильтрами (Bayer RGGB). В основе лежит глубокое обучение: архитектура NAFNet обучается совместной демозаике и шумоподавлению с комбинированной пространственно-частотной функцией потерь (L1 + Focal Frequency Loss).

**Основные возможности:**
- Физически достоверная генерация обучающих пар LQ/HQ (сжатие, PSF, маска Байера, коррелированный шум).
- Обучение NAFNet с полным логированием метрик (CSV, TensorBoard, текстовые логи).
- Валидация с сохранением восстановленных изображений и расчётом PSNR/SSIM.
- Сравнение с классическими методами демозаики (билинейная интерполяция).
- Конфигурируемый графопостроитель для диссертационных иллюстраций.

## Быстрый старт

### Установка и настройка окружения
Подробная инструкция по развёртыванию (виртуальное окружение, PyTorch с CUDA, интеграция NAFNet) описана в **[docs/INSTALL.md](docs/INSTALL.md)**.

### Генерация датасета и предобученческая проверка
Скрипт `run_pipeline.py` генерирует пары LQ/HQ, выполняет визуальный контроль и smoke-тест.  
Подробности: **[docs/PIPELINE.md](docs/PIPELINE.md)**.

### Обучение модели
Скрипт `run_training.py` запускает обучение NAFNet с комбинированной потерей.  
Подробности (включая архитектуру сети и все гиперпараметры): **[docs/TRAINING.md](docs/TRAINING.md)**.

### Построение графиков
Скрипт `plot_metrics.py` создаёт публикационно-готовые графики (loss, PSNR, SSIM, сравнение с baseline) из CSV-логов.  
Инструкция и пример конфигурации: **[docs/PLOT.md](docs/PLOT.md)**.

### Полная конфигурация проекта
Все возможные настройки (от физической деградации до архитектуры сети и логирования) с пояснениями собраны в **[docs/CONFIG.md](docs/CONFIG.md)**.

## Структура проекта

```
DeepPhotoRestore/
├── run_pipeline.py          # предобученческий конвейер
├── run_training.py          # обучение нейросети
├── plot_metrics.py          # построение графиков
├── libraries/               # все модули (pipeline_, training_, общие)
├── options/                 # YAML-конфигурации (train, plot)
├── experiments/             # результаты экспериментов (логи, чекпоинты, графики)
├── datasets/                # сгенерированный датасет
├── samples/                 # временные визуализации (если не перенаправлены)
└── docs/                    # документация (см. ссылки выше)
```

## Требования

- Python 3.12
- NVIDIA GPU с драйверами CUDA (рекомендуется) или CPU (медленно)
- Библиотеки из `requirements.txt` (устанавливаются автоматически, см. INSTALL.md)
