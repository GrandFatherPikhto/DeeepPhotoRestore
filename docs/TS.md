## Ключевые замечания по коду
1. Несоответствие типа данных в run_training.py
Строки 52–69: универсальный переключатель датасетов, но JPEGKeyPairDataset делает .convert('RGB') — это 3-канальный JPEG. Для RAW-задачи нужен 4-канальный вход (RGGB). Если вы обучаете на .jpg — это не RAW-реставрация, а обычный image-to-image translation.

### 2. evaluate_baseline.py — неполный расчёт

```python
# Строка 69: mhc_psnrs пустой список, никогда не заполняется
print(f"2. Градиентный метод (Edge-Aware MHC) : Средний PSNR = {np.mean(mhc_psnrs):.2f} dB")
# → np.mean([]) = nan, будет warning
```

### 3. run_training.py — нет FFL

```python
# Строка 84: только L1
criterion = nn.L1Loss() # Наш злой L1 лосс против мыла!
```

Нужно:

```python
criterion = CombinedLoss(l1_weight=1.0, ffl_weight=1.0)
```

4. Отсутствующие зависимые модули

run_training.py импортирует: environment, checkpoint_io, model_loader, validator, logger, dataset_nef — ни одного из этих файлов в загрузке нет.
