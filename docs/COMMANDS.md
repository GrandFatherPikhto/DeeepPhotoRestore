# Команды запуска

```bash
CUDA_VISIBLE_DEVICES=0 python3 basicsr/train.py -opt options/train/Tanahen/train_NAFNet_JPEG.yml
```

```bash
CUDA_VISIBLE_DEVICES=0 python3 basicsr/train.py -opt options/train/Tanahen/train_vgg19.yml
```

Вот краткий, шпаргалочный гайд по командам запуска. Он разбит по шагам, чтобы ты мог быстро скопировать нужную строчку и запустить процесс в терминале.
------------------------------
## 🧱 ПЕРЕД КАЖДЫМ ЗАПУСКОМ (Подготовка окружения)
Перед тем как вводить любую команду обучения, обязательно зайди в папку нейросети и включи твой виртуальный мир библиотек:

# 1. Переходим строго в папку репозитория
cd /home/grand/Projects/Python/Tanahen/NAFNet
# 2. Активируем виртуальное окружение
source ../.venv/bin/activate

(Индикатор успеха: в начале строки терминала загорелась надпись (.venv)).
------------------------------
## 🏎️ КОМАНДА 1. Быстрый базовый запуск (Только пиксели)
Эта команда запускает классическое обучение нейросети NAFNet. В качестве судьи используется только один попиксельный учитель — L1Loss.

CUDA_VISIBLE_DEVICES=0 python3 basicsr/train.py -opt options/train/Tanahen/train_NAFNet_JPEG.yml


* Когда использовать: Для быстрой технической проверки датасета, базовой обкатки модели и скоростной зачистки пикселей от шума.
* Плюсы: Работает быстрее, видеокарта RTX 4070 Ti почти не греется, тратит минимум видеопамяти.
* Результат весов: Сохраняются в файлы net_g_XXXX.pth внутри папки experiments/NAFNet-JPEG-4070Ti/models/.

------------------------------
## 🎨 КОМАНДА 2. Продвинутый запуск (Пиксели + Восприятие человека)
Эта команда запускает улучшенное обучение с нашим кастомным коктейлем лоссов. Здесь работают сразу два учителя: L1Loss (чистит цвет) и созданный нами PerceptualLoss на базе шпиона VGG-19 (дорисовывает живую текстуру).

CUDA_VISIBLE_DEVICES=0 python3 basicsr/train.py -opt options/train/Tanahen/train_vgg19.yml


* Когда использовать: Для финального боевого обучения на большом датасете, чтобы картинки на выходе получались максимально сочными, резкими и фотореалистичными.
* Плюсы: Картинка не будет «замыливаться», ИИ учится восстанавливать сложную структуру кадра (волосы, листву, кирпич).
* Результат весов: Сохраняются в файлы net_g_XXXX.pth внутри папки experiments/NAFNet-JPEG-4070Ti-vgg19/models/.

------------------------------
## 🔍 РАСШИФРОВКА ФЛАГОВ КОМАНДЫ (Для шпаргалки):

* CUDA_VISIBLE_DEVICES=0 — жесткий приказ для Python: «Задействовать для расчетов строго первую видеокарту NVIDIA (твою RTX 4070 Ti) и игнорировать процессор».
* python3 basicsr/train.py — запуск главного скрипта-движка, который собирает слои нейросети воедино.
* -opt — флаг (сокращение от options), после которого мы передаем движку путь к текстовому рецепту обучения.
