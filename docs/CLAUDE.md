## 1. Зачем весь этот проект вообще нужен

Современные камеры — особенно в смартфонах, дронах, экшн-камерах и медицинских устройствах — оснащены **малогабаритными сенсорами с мозаичными светофильтрами** (матрица Байера). Это значит, что каждый пиксель матрицы физически видит лишь один из трёх цветов: красный, зелёный или синий. Полноцветная картинка из таких данных — это всегда результат математической реконструкции, и реконструкция эта несовершенна.

Итоговое изображение в итоге страдает сразу от нескольких проблем:

- **Цветовые артефакты и ложные цвета** — следствие интерполяции мозаичного сигнала (демозаики).
- **Шумы сенсора** — особенно при слабом освещении.
- **Артефакты сжатия** — как только камера сохраняет снимок в JPEG, алгоритм сжатия вносит характерные блочные искажения («кубики», потеря мелких деталей).
- **Потеря детализации** — мелкая текстура (волосы, ткань, листья) размывается или исчезает.

**Цель диссертации** — исследовать и разработать методы, которые нейтрализуют все эти проблемы на программном уровне, то есть научить нейронную сеть автоматически восстанавливать качество испорченного изображения.

## 2. Что конкретно исследуется

Работа структурирована по трём ключевым направлениям, каждое из которых — отдельная глава диссертации:

### Глава 1. Пространственная обработка (демозаика и реставрация)
Анализ конструктивных особенностей малогабаритных сенсоров. Как устроена матрица Байера, какие алгоритмы демозаики существуют (билинейная, AHD, VNG, ML-based) и как нейросеть может делать это лучше классики.

### Глава 2. Пространственно-цветовая реставрация
Исследование методов восстановления пространственно-цветовой структуры изображения. Главный акцент — на том, как убрать артефакты сжатия (JPEG-блоки) и восстановить мелкие детали, которые сжатие «съело».

### Глава 3. Временная обработка (видеопоток)
Как применять методы реставрации не к одному кадру, а к последовательности кадров видео с одноматричной камеры. Использование временной корреляции между кадрами для улучшения качества.

### Глава 4. Экспериментальная проверка
Обучение нейросетевых моделей на реальных данных, замер метрик качества (PSNR, SSIM), визуальное сравнение результатов.

## 3. Стек технологий и что куда поставили

Весь проект работает в **WSL 2** (Windows Subsystem for Linux, Ubuntu) с проброшенной видеокартой RTX 4070 Ti.

### Операционная среда

| Компонент | Что это | Зачем |
|-----------|---------|-------|
| **Windows 11 + WSL 2** | Виртуальная Ubuntu внутри Windows | Нейросети работают стабильнее на Linux; WSL 2 даёт полный доступ к GPU |
| **Ubuntu (WSL 2)** | Рабочая ОС | Все команды запускаются здесь |
| **RTX 4070 Ti (12 ГБ VRAM)** | Видеокарта | Обучение нейросетей в десятки раз быстрее, чем на CPU |

> ⚠️ **Важно:** драйвер Nvidia устанавливается **только на Windows**. Внутри WSL устанавливается только CUDA Toolkit, но не драйвер. Windows автоматически «пробрасывает» GPU в WSL.

## 4. Данные: откуда берём и как готовим

### 4.1 Исходные датасеты (RAW-фотографии)

Для обучения нужны высококачественные **оригинальные (необработанные) RAW-снимки**. Используются два датасета:

| Датасет | Объём | Формат | Особенности |
|---------|-------|--------|-------------|
| **MIT-Adobe FiveK** | 5 000 фото | `.DNG` | Профессиональная съёмка: яркие и тёмные сцены, портреты, архитектура, пейзажи. Ровно 5 000 снимков — идеально под требования ТЗ |
| **RAISE Dataset** | 8 156 фото | RAW (несжатые) | Можно скачать отфильтрованными частями: RAISE-4k или RAISE-6k |

**Требования к датасету:**
- Высокое разрешение (чтобы при сжатии был виден эффект, а не один серый пиксель)
- Не менее 4–5 тысяч фотографий
- Разнообразие сцен: тёмные, яркие, с мелкой детализацией (шерсть, ткань, трава)
- Необработанный формат (RAW/DNG)

### 4.2 Создание обучающих пар (имитация сжатия)

Нейросеть учится на **парах**: «испорченная фотография → оригинал». Испорченные версии создаём программно с помощью Pillow:

**Алгоритм 1 — JPEG-блоки:**  
Сохраняем оригинал в JPEG с очень низким качеством (`quality=10–20`). Создаются характерные блочные артефакты и замыливание деталей.

**Алгоритм 2 — Даунсэмплинг + JPEG:**  
Сначала уменьшаем разрешение в 2–4 раза (метод Bicubic), затем применяем JPEG-сжатие. Классический подход для обучения моделей типа Real-ESRGAN.

### 4.3 Разбиение датасета на Train / Test (95% / 5%)

```python
import os, shutil, random
from PIL import Image

SOURCE_DIR    = "source_images"
TRAIN_HQ      = "dataset_ready/train/hq_targets"  # оригиналы для обучения
TRAIN_LQ      = "dataset_ready/train/lq_inputs"   # сжатые для обучения
TEST_HQ       = "dataset_ready/test/hq_targets"   # оригиналы для теста
TEST_LQ       = "dataset_ready/test/lq_inputs"    # сжатые для теста

for folder in [TRAIN_HQ, TRAIN_LQ, TEST_HQ, TEST_LQ]:
    os.makedirs(folder, exist_ok=True)

def compress_image(src, dst, quality=15):
    with Image.open(src) as img:
        if img.mode != 'RGB':
            img = img.convert('RGB')
        img.save(dst, "JPEG", quality=quality)

all_images = [f for f in os.listdir(SOURCE_DIR) if f.lower().endswith(('.jpg', '.png', '.dng'))]
random.seed(42)
random.shuffle(all_images)

split_idx   = int(len(all_images) * 0.95)
train_files = all_images[:split_idx]   # ~95%
test_files  = all_images[split_idx:]   # ~5%

def process(files, hq_dir, lq_dir):
    for fname in files:
        src  = os.path.join(SOURCE_DIR, fname)
        base = os.path.splitext(fname)[0]
        # Оригинал → HQ (без изменений, в PNG)
        with Image.open(src) as img:
            img.save(os.path.join(hq_dir, base + ".png"), "PNG")
        # Сжатая копия → LQ
        compress_image(src, os.path.join(lq_dir, base + ".jpg"), quality=15)

process(train_files, TRAIN_HQ, TRAIN_LQ)
process(test_files,  TEST_HQ,  TEST_LQ)
print("Готово! Датасет разложен по папкам.")
```

После выполнения скрипта папка `dataset_ready/` содержит все нужные пары. Папку `lq_inputs` можно открыть глазами и сразу увидеть, как JPEG «пошакалил» снимки.

## 5. Модели нейросетей

Для задачи устранения артефактов сжатия (Image Artifact Removal / Image Restoration) выбраны три готовых архитектуры. Все написаны на PyTorch, все доступны через фреймворк BasicSR.

### NAFNet — основная рабочая лошадка ✅

**Nonlinear Activation Free Network.** Лучший практический выбор для домашнего GPU.

- Убрали тяжёлые нелинейные функции активации — сеть значительно легче и быстрее аналогов.
- Прекрасно убирает JPEG-блоки и восстанавливает плавность текстур.
- Комфортно работает на 12 ГБ VRAM (RTX 4070 Ti).
- Есть готовые веса и конфигурации для задачи JPEG Artifact Reduction.

### SwinIR — мощная альтернатива

Модель на базе Vision Transformers (родственная технология того же transformer-а, что в ChatGPT, но адаптированная для пикселей).

- Превосходно восстанавливает мелкую детализацию: волосы, ткань, текст, текстуры.
- Есть официальный режим `JPEG Artifact Reduction` «из коробки».
- Требует больше VRAM, чем NAFNet — на 12 ГБ работает, но с меньшим batch size.

### Real-ESRGAN — если нужен апскейл

Если задача не просто убрать сжатие, но и **увеличить разрешение** (x2, x4), то это лучший выбор. Предобучена на восстановлении сильно испорченных снимков.

### Стратегия обучения: Fine-Tuning, не с нуля

**Не нужно обучать модель с нуля.** Это заняло бы недели вычислений.

Правильная стратегия (заложена в ТЗ):
1. Скачать предобученную модель (NAFNet или SwinIR) — она уже умеет «видеть» структуру изображений.
2. Провести **дообучение (Fine-Tuning)** на нашем датасете из 5 000 фотографий.
3. Сеть «донастроится» под специфику нашего алгоритма сжатия за разумное время.

## 10. Метрики качества

Результаты оцениваются двумя стандартными объективными метриками + глазами:

| Метрика | Что измеряет | Интерпретация |
|---------|-------------|---------------|
| **PSNR** (Peak Signal-to-Noise Ratio) | Отношение сигнала к шуму в дБ | Чем выше — тем лучше. Типично: >30 дБ — хорошо, >35 дБ — отлично |
| **SSIM** (Structural Similarity Index) | Структурное сходство двух изображений | От 0 до 1. Близко к 1 — хорошо |
| **Визуальная оценка** | Субъективное сравнение | Смотрим на сжатое, результат модели и оригинал рядом |

BasicSR автоматически считает PSNR и SSIM на тестовой выборке в процессе обучения и логирует их каждые 5 000 итераций.

## 11. Конфигурация обучения

Ключевые параметры конфига `options/train/NAFNet-JPEG-4070Ti.yml`:

```yaml
name: NAFNet-JPEG-4070Ti
model_type: ImageRestorationModel
num_gpu: 1             # одна RTX 4070 Ti
manual_seed: 42

datasets:
  train:
    dataroot_gt: ../dataset_ready/train/hq_targets   # оригиналы
    dataroot_lq: ../dataset_ready/train/lq_inputs    # сжатые
    gt_size: 256          # патчи 256×256 пикселей
    batch_size_per_gpu: 8 # 8 картинок за шаг (ок для 12 ГБ VRAM)
    use_flip: true        # аугментация: зеркальное отражение
    use_rot: true         # аугментация: повороты

  val:
    dataroot_gt: ../dataset_ready/test/hq_targets
    dataroot_lq: ../dataset_ready/test/lq_inputs

network_g:
  type: NAFNet
  width: 32
  enc_blk_nums: [2, 2, 4, 8]
  middle_blk_num: 12
  dec_blk_nums: [2, 2, 2, 2]

train:
  optim_g:
    type: AdamW
    lr: 1e-3
  total_iter: 200000     # всего 200 тысяч шагов обучения
  scheduler:
    type: TrueCosineAnnealingLR

logger:
  save_checkpoint_freq: 5000   # сохранять чекпоинт каждые 5к шагов
  metrics:
    psnr: {type: calculate_psnr}
    ssim: {type: calculate_ssim}
```

## 12. Роль локальной LLM (Llama)

По требованиям ТЗ (пункт 4: «реализовать алгоритм с помощью любой LLM на питоне») в проект интегрирована локальная языковая модель Llama (через Ollama).

**Важно понимать:** Llama — это текстовая модель. Она **не обрабатывает пиксели** и не заменяет NAFNet. Её роль — инструмент разработчика:

| Задача | Как помогает Llama |
|--------|-------------------|
| Генерация Python-кода | Пишет Dataset-классы, скрипты конвертации RAW, скрипты аугментации |
| Разбиение датасета | Генерирует скрипт train/test split по промпту |
| Отладка ошибок | Получает traceback из PyTorch, объясняет причину и предлагает исправление |
| Написание конфигов | Помогает составить .yml для BasicSR |

```python
import ollama

response = ollama.chat(model='llama3', messages=[{
    'role': 'user',
    'content': '''Напиши класс Dataset на PyTorch для загрузки пар картинок.
    Оригиналы лежат в папке hq_targets/, сжатые — в lq_inputs/.
    Имена файлов одинаковые, расширения разные (.png и .jpg соответственно).'''
}])

print(response['message']['content'])
```

Llama запускается через Ollama и доступна без интернета — удобно для работы в закрытой исследовательской среде.
