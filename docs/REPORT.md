# Конвейер генерации визуальных отчётов (Deep Photo Restoration Pipeline)

Автоматизированный инструмент для контроля качества обучения нейросетей восстановления изображений. Скрипт объединяет поиск тестовых данных, автоматическую RAW-демозаику, валидацию результатов эпох, расчёт математических метрик (PSNR/SSIM) и физическую склейку сравнительных изображений.

---

## 1. Для чего предназначен скрипт

Скрипт решает задачу наглядной и количественной оценки качества работы модели на этапе тестирования или валидации. Он выполняет:

1. **Генерацию конфига отчёта (YAML)** – собирает структуру пар для склейки и записывает глобальные параметры отображения.
2. **Автоматическую генерацию LQ-превью** – если в папке эксперимента отсутствуют PNG-превью для исходных данных, скрипт на лету берёт 4-канальные RAW-файлы (`.tiff`/`.tif`) из датасета и прогоняет их через билинейную демозаику.
3. **Расчёт метрик качества** – автоматически вычисляет **PSNR (dB)** и **SSIM** для восстановленного кадра финишной эпохи относительно идеального референса (HQ).
4. **Физическую склейку (Side-by-Side)**:
   * **Пары Эпох** (`report/epochs/`) – сравнение визуального прогресса между стартовой (например, `epoch_0`) и финишной эпохами. На изображение финишной эпохи накладывается полупрозрачная плашка с метриками.
   * **Пары Исходников** (`report/source/`) – сравнение оригинального таргета (HQ) и входного зашумленного кадра (LQ). Метрики для этой пары не считаются (бессмысленно).

## 2. Источники данных (Откуда берутся файлы)

Скрипт динамически считывает базовый конфигурационный файл обучения (`-opt`), заменяет в нём плейсхолдер `{name}` на реальное имя эксперимента и обращается к двум главным директориям:

### А. Директория датасета (`dataset_root`)
Из подпапки `test/` извлекаются:
* `test/lq_inputs/DSC_{XXXX}_bayer.tiff` (или `.tif`) – исходные 4-канальные RAW-кадры. По их номерам строится вся очередь обработки.
* `test/hq_targets/DSC_{XXXX}.png` – идеальные референсы для склейки и расчёта метрик.

### Б. Директория эксперимента (`experiment_dir`)
Сюда скрипт складывает промежуточные данные и забирает результаты сети:
* `lq_preview/DSC_{XXXX}_bayer.png` – папка для кэширования сгенерированных LQ-превью.
* `val_predictions/epoch_{N}_DSC_{XXXX}.png` – предсказания нейросети для указанных эпох.
* `report/` – итоговая папка, куда сохраняются склейки (разделенные по папкам `epochs` и `source`).

## 3. Ключи запуска (Аргументы командной строки)

### Обязательные ключи
* `-opt` *(str)*: Путь к исходному YAML-конфигу обучения (например, `options/training/NAFNet_200_02.yml`).
* `--finish_epoch` *(str)*: Номер финишной (конечной) эпохи, результаты которой нужно оценить.

### Параметры логики конвейера
* `--start_epoch` *(str)*: Номер стартовой эпохи для сравнения. *По умолчанию: `0`*.
* `--output` *(str)*: Путь для сохранения сгенерированного YAML-файла отчёта. *По умолчанию: `./report.yml`*.

### Параметры графики (Разметка и холст)
* `--image_size` *(W,H)*: Размер, к которому будут приведены изображения перед склейкой. Задается строкой через запятую. *По умолчанию: `512,512`*.
* `--spacing` *(int)*: Зазор (расстояние) между левой и правой картинкой в пикселях. *По умолчанию: `10`*.
* `--background_color` *(R,G,B или R,G,B,A)*: Цвет фона холста и зазора. Можно передать 3 числа (RGB) или 4 (RGBA) для прозрачного фона. *По умолчанию: `255,255,255` (белый непрозрачный)*.

### Настройки рамок (Borders)
* `--border_disabled`: Флаг отключения отрисовки рамок вокруг изображений. Если не передан — рамки включены.
* `--border_color` *(R,G,B)*: Цвет линии рамки. *По умолчанию: `0,0,255` (синий)*.
* `--border_thickness` *(int)*: Толщина рамки в пикселях. *По умолчанию: `1`*.

### Настройки метрик (Metrics)
* `--metrics_disabled`: Флаг полного отключения вывода PSNR/SSIM на склейках.
* `--metrics_list` *(str)*: Перечень метрик для расчёта через запятую. Доступны: `psnr`, `ssim`. *По умолчанию: `psnr,ssim`*.
* `--metrics_position` *(str)*: Угол для размещения плашки с метриками. Выбор из: `top_left`, `top_right`, `bottom_left`, `bottom_right`. *По умолчанию: `top_left`*.
* `--metrics_color` *(R,G,B)*: Цвет шрифта для метрик. *По умолчанию: `255,255,255` (белый)*.

## 4. Примеры запуска

### Минимальный запуск (Всё по дефолту)
Скрипт сам найдёт кадры, при необходимости сгенерирует недостающие LQ, рассчитает PSNR/SSIM, выведет их в левый верхний угол и склеит картинки в размер 512x512 с белым фоном:

```bash
./generate_reports.py -opt options/training/NAFNet_200_02.yml --finish_epoch 3890
```

### Полный запуск с кастомизацией
Запуск со сравнением 500-й и 4000-й эпох, сохранением конфига в кастомную папку, ресайзом до 1024x1024, увеличенным зазором, отключенными рамками и выводом только PSNR в правый нижний угол:

```bash
./generate_reports.py \
  -opt options/training/NAFNet_200_02.yml \
  --start_epoch 500 \
  --finish_epoch 4000 \
  --output options/reports/NAFNet_200_02_report.yml \
  --image_size 1024,1024 \
  --spacing 20 \
  --border_disabled \
  --metrics_list psnr \
  --metrics_position bottom_right
```

### Прозрачный фон (для PNG)
Если вы сохраняете склейки в PNG и хотите, чтобы фон был прозрачным, укажите `--background_color 0,0,0,0` (четыре числа):

```bash
./generate_reports.py -opt config.yml --finish_epoch 1000 --background_color 0,0,0,0
```

## 5. Выходная структура папок

После успешного выполнения внутри директории эксперимента (`experiment_dir`) появится папка `report/`:

```
experiment_dir/
└── report/
    ├── epochs/                      # склейки эпох (start vs finish)
    │   └── epoch_0_3890_DSC_0001.png
    │   └── epoch_0_3890_DSC_0002.png
    │   └── ...
    ├── source/                      # склейки исходников (HQ vs LQ)
    │   └── hq_lq_DSC_0001.png
    │   └── hq_lq_DSC_0002.png
    │   └── ...
    └── ... (другие файлы, если есть)
```

## 6. Примечания

* **Метрики рассчитываются только для пар эпох** (где `output` содержит подстроку `epochs`). Для пар исходников метрики не выводятся.
* Для работы SSIM **рекомендуется установить** библиотеку `scikit-image`: `pip install scikit-image`. Если она отсутствует, SSIM не будет рассчитан (выдаст предупреждение).
* Если исходный LQ-файл имеет суффикс `_bayer` в имени, он будет найден автоматически. Поддерживаются расширения `.tiff` и `.tif`.
* Все промежуточные PNG-превью генерируются один раз и кэшируются в `lq_preview/`, чтобы ускорить повторные запуски.
* Скрипт автоматически создаёт все необходимые папки для выходных файлов (в том числе `report/epochs/` и `report/source/`).

## 7. Возможные ошибки и их решение

| Ошибка | Решение |
|--------|---------|
| `FileNotFoundError: .../DSC_XXXX_bayer.tiff` | Убедитесь, что в `dataset_root/test/lq_inputs/` есть файлы с нужными номерами. |
| `ValueError: bad transparency mask` | Используйте последнюю версию скрипта (с поддержкой RGBA) или укажите `--background_color` в формате RGB (3 числа). |
| `NameError: name 'bilinear_demosaic_rggb' is not defined` | Убедитесь, что модуль `libraries.pipeline_visuals` существует и содержит эту функцию. |
| `ImportError: cannot import name 'structural_similarity'` | Установите `scikit-image`: `pip install scikit-image` (SSIM не обязателен, но желателен). |
