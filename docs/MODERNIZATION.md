# 📝 README: Модернизация программного комплекса DeepPhotoRestore
## 🔬 Краткое описание проблемы (До рефакторинга)
В исходной архитектуре программного комплекса наблюдался критический доменный сдвиг диапазонов нормализации данных (data domain shift) между этапом синтеза деградаций и этапом глубокого обучения. Скрипт prepare_dataset.py генерировал одномерную мозаику в целочисленном формате uint16 (но со значениями 0–255), в то время как класс CustomNEFPairDataset в цикле обучения ожидал честное разложение на 4 канала и выполнял деление на 65535.0 [prepare_dataset.py, dataset_nef.py].
Это приводило к градиентной слепоте (gradient vanishing) модели NAFNet — входной LQ-сигнал аппроксимировался к околонулевым значениям (~ 0.003), вследствие чего нейросеть восстанавливала только постоянную составляющую поля, генерируя плоское усреднённое цветовое мыло («оранжевый квадрат»).
------------------------------
## 🛠️ Перечень внесенных исправлений в кодовую базу## 1. Архитектурная декомпозиция кода (Изоляция математики)

* Было: Скрипт prepare_dataset.py содержал внутри себя линейную логику автоматизации, ввода-вывода и низкоуровневые формулы деградаций (более 250 строк). Это усложняло отладку и нарушало принцип единственной ответственности (SOLID / SRP).
* Стало: Создана внешняя библиотека libraries/degradation.py. В неё инкапсулирована вся физико-математическая модель оптического тракта: генерация ядер ЧКХ объектива через Гауссиану, моделирование АБГШ, наложение маски Байера (RGGB) и аппаратная нарезка мозаики на 4 частотных подканала.

## 2. Синхронизация и масштабирование шкал интенсивностей

* Было: Числа внутри файла .tiff оставались в диапазоне 0–255 при контейнере uint16, что ломало нормализацию тензоров.
* Стало: Внутри метода synthesize_lq интегрировано честное спектральное растяжение сигнала из 8-битного диапазона оригинальной sRGB-картинки в истинный 16-битный динамический диапазон сенсора: bayer_16bit = (bayer / 255.0 * 65535.0).

## 3. Ранняя экстракция RGGB подканалов

* Было: Метод _extract_bayer_channels пытался нарезать каналы из RGB-оригинала, полностью игнорируя наложенную маску и зашумление. Скрипт Baseline-сравнения падал в аномальные 4.28 dB.
* Стало: Пайплайн перестроен в соответствии с физикой сенсора: Уменьшение разрешения -> Наложение маски Байера -> Зашумление ЧКХ -> Экстракция 4 каналов. На диск теперь записывается честный 4-канальный 16-битный TIFF пакет, готовый к батчеванию. Из dataset_nef.py удалена дублирующая нарезка, а нормализация приведена к аппаратному стандарту / 65535.0.

## 4. Защита от нечетной геометрии кадров матрицы

* Было: При обработке реальных снимков с камеры Nikon D600 с нечетным разрешением матрицы (например, по ширине), NumPy падал с ошибкой ValueError: all input arrays must have the same shape [dataset_nef.py, validator.py].
* Стало: В методы нарезки каналов внутри libraries/degradation.py и libraries/validator.py внедрен геометрический щит, принудительно усекающий крайний нечетный ряд пикселей: h = h - (h % 2); w = w - (w % 2).

## ➕ Новые добавленные модули программного комплекса
Для усиления верификационной (практической) составляющей диссертации в проект были интегрированы 4 автономных исполняемых скрипта с поддержкой Unix-шебанга #!./.venv/bin/python3:

| Название скрипта | Выполняемая научная / практическая задача | Время работы |
|---|---|---|
| libraries/losses.py | Частотный лосс (Focal Frequency Loss). Переводит предсказание и таргет в частотный домен через 2D БПФ (FFT). Вычисляет L1-расстояние между амплитудными спектрами с динамическим фокусирующим весом. Заставляет сеть генерировать утерянные частоты Найквиста [losses.py]. | Мгновенно (GPU) |
| smoke_test.py | Дымовое тестирование графа вычислений. Автономно берет 1 случайный кадр, прогоняет через датасет, модель NAFNet и гибридный лосс (L1 + FFT). Проверяет Мин/Макс значения тензоров и выводит диагностику до старта долгого обучения [smoke_test.py]. | ~2 сек. |
| check_visuals.py | Визуальный контроль конвейера. Делает обратную сборку сгенерированного 4-канального TIFF в RGB-превью и сохраняет его в корень (debug_lq_preview.png) рядом с оригиналом. Позволяет глазами оценить структуру шума и ЧКХ до обучения. | <1 сек. |
| evaluate_baseline_min.py | Оценка классических алгоритмов. Реализует математически строгий билинейный фильтр низких частот (ФНЧ) для текущей структуры данных, формируя эталонную точку отсчета (Baseline в dB) для сравнительных таблиц диссертации. | <1 сек. |
| profile_model.py | Профилирование сложности модели. Вычисляет точный объем параметров NAFNet, теоретическую сложность в GFLOPs, а также замеряет чистую скорость инференса видеокарты (FPS / Latency в мс) [profile_model.py]. | ~5 сек. |

## 🚀 Актуализированный регламент запуска экспериментов

# Шаг 1. Развернуть и подготовить физически адекватный датасет (с очисткой старого кэша)
./prepare_dataset.py -opt options/train/RAW_NAFNet_NikonD600.yml --clean
# Шаг 2. Визуально проверить глазами сгенерированные файлы (контроль цвета и зерна шума)
./check_visuals.py
# Шаг 3. Запустить автоматический тест диапазонов чисел и backward-градиентов PyTorch
./smoke_test.py
# Шаг 4. Рассчитать базовый уровень качества классического фильтра для таблиц ВАК
./evaluate_baseline_min.py
# Шаг 5. Запустить полноценное высокоскоростное обучение NAFNet (Батч 16, 2 воркера)
python run_training.py -opt options/train/RAW_NAFNet_NikonD600.yml
