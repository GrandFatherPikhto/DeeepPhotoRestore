# Проект: Обучение нейросети (NAFNet) для демозаики (RAW → RGB)

## Задачи исследования и этапы разработки
### Теоретическая база и анализ артефактов

   1. Анализ пространственной модели формирования изображения: Описание сквозного процесса прохождения сигнала: «объектив (линза) $\rightarrow$ массив цветофильтров (CFA) $\rightarrow$ светочувствительная матрица».
   2. Математическое описание дискретизации: Представление матрицы в виде сетки дельта-функций в каждом отсчете.
   3. Моделирование частотных структур:
   * Разработка математической структуры для канала яркости (по зеленому фильтру).
      * Разработка аналогичных структур для каналов цветности (для красного и синего фильтров).
   4. Спектральный анализ: Расчет спектров дискретизации для сформированных структур яркости и цветности.
   5. Моделирование искажений: Выполнение операции свертки. Обоснование эффекта «выпадания» частотных диапазонов и математическое описание необходимости их восстановления (интерполяции потерянных частот) с помощью аппарата обучаемых нейросетей.
   6. Анализ артефактов демозаики: Исследование природы и характеристик искажений, возникающих при разделении цветовых каналов.
   7. Анализ кодеков сжатия: Поиск и систематизация существующих кодеков с подробным описанием вносимых ими артефактов.
   8. Изучение референсов: Использование материалов файла «диссер122» в качестве методологического примера (с поправкой на специфику задач демозаики).

### Разработка датасета и обучение модели

   1. Сбор и фильтрация данных: Сравнение существующих открытых датасетов. Выбор наиболее адекватных базовых данных для сборки собственного структурированного набора изображений.
   2. Критерии подбора снимков: Включение в датасет изображений с обильной высокочастотной текстурой (кирпичные стены, мелкие детали) и выраженными резкими границами объектов для оценки работы алгоритмов в критических режимах.
   3. Объем данных: Формирование выборки объемом от 100 до 1000 уникальных изображений (с учетом аугментации).
   4. Дообучение нейросети: Тонкая настройка (fine-tuning) модели на созданном целевом датасете для эффективного восстановления утерянных частотных диапазонов.

### Алгоритм обработки данных (Pipeline)

   1. Генерация каналов: Корректное распределение отсчетов: обработка зеленого канала (по четным позициям) и масштабирование этого принципа на красный и синий каналы.
   2. Понижение разрешения: Формирование исходных RAW-изображений путем уменьшения пространственного разрешения оригинальных снимков в 4 и 8 раз по обоим направлениям.
   3. Моделирование шума на основе ЧКХ: Расчет параметров накладываемого шума:


* Анализ тестового изображения для замера частотно-контрастной характеристики (ЧКХ).
* Выполнение свертки изображения с аддитивным белым гауссовским шумом (АБГШ), характеристики которого адаптированы под полученную ЧКХ.


   1. Формирование пар сравнения: Создание двух параллельных потоков данных — с наложением смоделированного АБГШ и абсолютно «чистых» (без шума).
   2. Аугментация данных: Применение геометрических трансформаций (включая повороты) для кратного увеличения объема обучающей выборки.
   3. Тестирование и валидация: Выполнение финальной демозаики обработанных кадров и проведение объективного сравнительного анализа полученных изображений с референсными исходниками.

## Что сделано

1. **Анализ и моделирование**
   - Построена математическая модель формирования сигнала в одноматричной камере (линза → цветофильтр Байера → дискретизация → шум).
   - Проведён спектральный анализ потерь высоких частот для красного и синего каналов, обоснована необходимость использования зелёного канала для восстановления.
   - Найдены и проанализированы артефакты демозаики (муар, ложные цвета, потеря резкости).

2. **Подготовка данных**
   - Разработан скрипт `prepare_dataset_raw.py`, который:
     - Читает RAW-файлы (Nikon D600, `.nef`) через библиотеку `imageio`.
     - Извлекает эталонное RGB-изображение (HQ) через `rawpy.postprocess()`.
     - Синтезирует байеровский массив (LQ) с возможным уменьшением разрешения и добавлением шума.
     - Сохраняет HQ как 8-бит PNG, LQ — как 16-бит TIFF.
     - Создаёт структуру папок `train/` и `test/` с разбиением 95/5.
   - Сгенерирован датасет из 11 пар (11 RAW → 11 пар LQ/HQ) с аугментацией (повороты, отражения).

3. **Настройка обучения NAFNet**
   - Выбрана архитектура NAFNet (BasicSR) как современная и эффективная для восстановления изображений.
   - Написан кастомный даталоадер `my_basicsr/data/raw_dataset.py`, который:
     - Читает `.tiff` (LQ) и `.png` (HQ).
     - Нормализует LQ в [0,1] (uint16 → float32 / 65535).
     - Преобразует одноканальный LQ в 3-канальный повторением канала.
     - Выполняет случайный кроп 256×256 и аугментации (flip, rotate).
   - Создан скрипт запуска `run_training_register.py`, который регистрирует датасет в BasicSR через добавление модуля в `_dataset_modules` (без изменения кода NAFNet).
   - Настроен конфигурационный YAML `train_NAFNet_RAW_4070Ti.yml` со следующими параметрами:
     - `img_channel: 3` (вход RGB, но фактически три копии байера)
     - `total_iter: 200000` (можно уменьшить до 5000–10000 для теста)
     - `dataset_enlarge_ratio: 100` – повтор данных (но параметр работает только внутри `datasets.train`)
     - `print_freq: 10` – частая печать логов.

4. **Результаты**
   - Обучение успешно запущено, loss снижается (с ~0.288 до ~0.234 за 10 итераций).
   - GPU (RTX 4070 Ti) загружен на ~10%, память ~6 ГБ.
   - Время одной итерации ~2 секунды (при batch_size=4, gt_size=256).

## Основные проблемы, которые были решены

- `rawpy` возвращал массив (1,1,3) для Nikon D600 → перешли на `imageio`.
- `basicsr.utils.registry` отсутствовал → написали даталоадер без регистрации, добавляем модуль через `_dataset_modules`.
- Несоответствие имён файлов (суффикс `_bayer`) → исправлено в даталоадере.
- Ошибки размерности при дублировании канала → добавлена проверка `ndim` и конкатенация.
- Параметр `dataset_enlarge_ratio` не срабатывал → перенесён в секцию `datasets.train`.

## Что можно улучшить

1. **Увеличить датасет** – использовать Zurich RAW to RGB или собрать больше своих RAW.
2. **Предобученные веса** – скачать `NAFNet-SIDD-width32.pth` для ускорения сходимости.
3. **Исправить `dataset_enlarge_ratio`** – перенести в `datasets.train` или реализовать повтор данных в даталоадере.
4. **Уменьшить `total_iter`** до 5000–10000 для быстрого теста качества.
5. **Написать инференс** – применить обученную модель к тестовому `.tiff` и сравнить с билинейной демозаикой.

## Roadmap (дорожная карта)

### 🧠 Восстановление изображений из RAW‑данных байеровского сенсора с помощью NAFNet

#### 📌 Постановка задачи

Цель работы — разработать метод повышения качества цветных изображений, получаемых с одноматричных сенсоров (камеры Nikon D600), на основе **глубокого обучения** и **физически обоснованного моделирования искажений**.

##### Основные этапы исследования

1. **Анализ артефактов демозаики**  
   Изучены искажения, возникающие при цветофильтрации (Байеровский массив RGGB): муар, ложные цвета, потеря высоких частот в красном и синем каналах.  
   Рассмотрена модель **Ferrara et al. (IEEE TIFS 2012)**, в которой показано, что дисперсия ошибки линейного предсказания на позициях приобретённых пикселей выше, чем на интерполированных.

2. **Спектральный анализ дискретизации**  
   Построена математическая модель дискретизации для зелёного, красного и синего каналов.  
   Показано, что для красного и синего каналов шаг дискретизации в два раза больше, что приводит к **наложению спектров (aliasing)** и потере высокочастотных деталей.  
   Зелёный канал (дискретизированный с частотой в 2 раза выше) сохраняет высокие частоты и может служить опорным при восстановлении.

3. **Синтез обучающего датасета**  
   Из 12 реальных RAW‑файлов (Nikon D600) сгенерированы пары «байеровский массив → полноцветное изображение»:
   - Чтение RAW (библиотека `rawpy`).
   - Извлечение эталонного RGB (`raw.postprocess`).
   - Синтез одноканального байеровского массива путём наложения маски RGGB.
   - Добавление шума (АБГШ + свёртка с ЧКХ, опционально).
   - Аугментация (повороты, отражения).
   - Сохранение пары: LQ — 16‑бит TIFF (байер), HQ — 8‑бит PNG (RGB).

4. **Выбор и адаптация модели**  
   Использована архитектура **NAFNet** (Nonlinear Activation Free Network) – современная модель для восстановления изображений, известная высокой эффективностью и низкой вычислительной сложностью.  
   Поскольку NAFNet ожидает 3 входных канала, а байеровский массив одноканальный, в даталоадере выполняется дублирование единственного канала трижды (простое, но эффективное решение).

5. **Обучение**  
   Написаны:
   - кастомный даталоадер `RawDataset`, наследующий `torch.utils.data.Dataset` (не требует регистрации в BasicSR);
   - скрипт запуска `run_training_register.py`, который динамически добавляет модуль датасета в `_dataset_modules` BasicSR (без изменения исходного кода NAFNet);
   - конфигурационный YAML‑файл для обучения.

6. **Результаты**  
   Обучение запущено, loss снижается с ~0.288 до ~0.234 за первые итерации, GPU загружен (RTX 4070 Ti, 6 ГБ памяти).  
   Датасет пока мал (11 обучающих пар), но процедура полностью работоспособна и может быть масштабирована.

## Конфигурация `prepare_dataset.py`

Конечно! Вот **подробное описание конфигурационного файла `prepare_dataset.json`** для скрипта `prepare_dataset_raw.py`. Этот файл управляет всеми этапами подготовки датасета из RAW-изображений.

---

# 📄 Конфигурационный файл `prepare_dataset.json`

Файл содержит параметры обработки RAW‑файлов и генерации пар (байеровский массив → эталонное RGB). Пример полного файла:

```json
{
    "source_dir": "nef_files",
    "output_dir": "dataset_ready",
    "train_ratio": 0.95,
    "seed": 42,
    "process": {
        "demosaic_method": "linear",
        "output_bps": 8,
        "downscale_factor": 2,
        "noise": {
            "add": false,
            "snr_db": 30,
            "correlated": true,
            "psf_sigma": 1.5
        }
    },
    "augmentation": {
        "enabled": false,
        "rotations": [0, 90, 180, 270],
        "horizontal_flip": true,
        "vertical_flip": true
    },
    "save_format": "png",
    "verbose": true
}
```

---

## 1. Общие настройки

| Поле | Тип | Описание | Пример |
|------|-----|----------|--------|
| `source_dir` | строка | Папка, содержащая исходные RAW‑файлы (`.nef`, `.cr2`, `.dng` и др.) | `"nef_files"` |
| `output_dir` | строка | Корневая папка, куда будет сохранён датасет. Внутри будут созданы подпапки `train/hq_targets`, `train/lq_inputs`, `test/...` | `"dataset_ready"` |
| `train_ratio` | число (0..1) | Доля файлов, идущая в обучающую выборку. Остальные — в тестовую. | `0.95` (95% train, 5% test) |
| `seed` | целое | Фиксирует случайное разбиение и аугментации для воспроизводимости. | `42` |

---

## 2. Секция `process` – параметры обработки изображения

### 2.1 Основные параметры

| Поле | Тип | Описание | Значения |
|------|-----|----------|----------|
| `demosaic_method` | строка | Алгоритм демозаики для получения эталонного RGB (HQ). | `"linear"` (по умолчанию), `"vng"`, `"ahd"`, `"dht"` (зависит от `rawpy`) |
| `output_bps` | целое | Битность выходного RGB‑изображения. | `8` (стандарт), `16` (для высокой точности, но не все просмотрщики поддерживают) |
| `downscale_factor` | целое | Во сколько раз уменьшить разрешение байеровского массива (LQ) перед сохранением. | `2`, `4`, `8` (1 – не уменьшать). Уменьшение вынуждает модель восстанавливать высокие частоты. |

### 2.2 Секция `noise` – добавление шума

| Поле | Тип | Описание |
|------|-----|----------|
| `add` | логический | Включает добавление шума (`true` / `false`). |
| `snr_db` | число | Отношение сигнал/шум в децибелах. Чем меньше значение, тем шум сильнее. | `30` (слабый шум), `20`, `10` (сильный) |
| `correlated` | логический | Если `true`, шум коррелируется свёрткой с ядром ЧКХ (реалистичный шум сенсора). Если `false` – простой АБГШ. |
| `psf_sigma` | число | Сигма гауссова ядра для свёртки (имитация ЧКХ). Используется только при `correlated: true`. | `1.5` (чем больше, тем сильнее размытие шума) |

**Примечание по шуму:**  
При `correlated: true` сначала генерируется АБГШ, затем он свёртывается с гауссовым ядром (размер 15×15, сигма `psf_sigma`). Это моделирует тепловой и фотонный шум реального сенсора.

---

## 3. Секция `augmentation` – аугментация

| Поле | Тип | Описание |
|------|-----|----------|
| `enabled` | логический | Включает аугментацию (`true` / `false`). |
| `rotations` | массив чисел | Углы поворота (кратные 90°). | `[0, 90, 180, 270]` – все повороты |
| `horizontal_flip` | логический | Разрешить случайное отражение по горизонтали. |
| `vertical_flip` | логический | Разрешить случайное отражение по вертикали. |

**Важно:**  
Аугментация применяется **одновременно к LQ и HQ** (одинаковое преобразование). Повороты и отражения выполняются с вероятностью 50% для каждого типа.

---

## 4. Прочие настройки

| Поле | Тип | Описание |
|------|-----|----------|
| `save_format` | строка | Формат сохранения HQ‑изображений. LQ всегда сохраняется как 16‑битный TIFF. | `"png"` (единственный поддерживаемый) |
| `verbose` | логический | Выводить подробные сообщения в консоль. |

## 🧪 Как использовать

1. Создайте файл `prepare_dataset.json` с нужными параметрами.
2. Разместите RAW‑файлы в папке, указанной в `source_dir`.
3. Запустите скрипт:

```bash
python prepare_dataset_raw.py --config prepare_dataset.json
```

4. После выполнения структура `dataset_ready` будет содержать пары `hq_targets` (PNG) и `lq_inputs` (TIFF), разбитые на `train` и `test`.

#### 🔬 Теоретическое обоснование (для диссертации)

##### Спектральный анализ потерь при дискретизации
Математическая модель в стиле Mathcad:

- Для зелёного канала (шаг дискретизации `T`) спектральные копии не перекрываются при ограничении полосы `π/T`.
- Для красного/синего (шаг `2T`) происходит наложение спектров, что приводит к необратимой потере высоких частот.
- Это доказывает принципиальную необходимость «достраивания» высоких частот красного и синего каналов с использованием зелёного канала.

##### Сравнение с классическими методами
- Билинейная, градиентная, медианная демозаика (статья Ferrara) дают артефакты на резких границах и мелких текстурах.
- Нейросетевой подход (NAFNet), обученный на физически смоделированных данных, способен восстанавливать утерянные частоты и подавлять муар.

##### Практическая ценность
- Предложенный метод может быть использован в системах цифрового телевидения (DVB‑T, MPEG‑2) для улучшения качества исходного сигнала перед сжатием.
- Уменьшение артефактов демозаики снижает нагрузку на последующие этапы сжатия и повышает эффективность кодирования.
