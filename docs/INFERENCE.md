# Запуск и настройка результатов обучения
## Конфигурационный файл
Если вы решите запустить обучение на файле конфигурации train_NAFNet_JPEG_4070Ti.yml (например, перенесёте проект на мощный сервер или ПК с картой RTX 4070Ti) [ссылка на конфиг 4070Ti из истории], вам нужно изменить три ключевые группы настроек [ссылка на адаптацию под 1060 из истории]. Они адаптируют пути под вашу локальную структуру пакетов и ускорят сохранение результатов.
Вот точечный список изменений, которые нужно внести в этот YAML-файл:
1. Исправление путей к датасету (Самое важное)
Поскольку мы отказались от Bash-скрипта с ручным прокидыванием путей и сделали правильный pip install -e . [ссылка на установку пакета из истории], запуск будет идти напрямую из корня проекта. Две точки ../ в путях сломают инициализацию [ссылка на проблему путей из истории].
В блоке datasets: замените пути на относительные от корня:
yaml
    # Было: ../dataset_ready/...
    dataroot_gt: ./dataset_ready/train/hq_targets  
    dataroot_lq: ./dataset_ready/train/lq_inputs   
Используйте код с осторожностью.
(То же самое сделайте ниже для блока val: — замените ../ на ./).
2. Разгон логгера и частые сохранения
В оригинальном конфиге 4070Ti веса сохраняются раз в 5000 шагов (5e3) [ссылка на конфиг 4070Ti из истории]. Чтобы результаты откладывались чаще и вы могли тестировать их в любой момент, измените блок logger: [ссылка на настройку частых сохранений из истории]:
yaml
logger:
  print_freq: 50             # Вывод логов в консоль каждые 50 шагов (было 200)
  save_checkpoint_freq: 500  # Сохранение весов .pth каждые 500 шагов (было 5000)
  use_tb_logger: true
Используйте код с осторожностью.
3. Настройки под «железо» (Если запускаете на 4070Ti)
Если этот конфиг действительно будет работать на RTX 4070Ti 12GB, то параметры батча и потоков можно оставить высокими, как в тексте:
gt_size: 256 и batch_size_per_gpu: 8 — это отлично нагрузит 12 ГБ видеопамяти [ссылка на конфиг 4070Ti из истории].
Единственное, проверьте параметр num_worker_per_gpu: 4 [ссылка на конфиг 4070Ti из истории]. Если процессор на той машине слабый, можно снизить до 2, чтобы не было фризов системы.
Как запускать этот конфиг после правок:
Так как пути у нас теперь настроены через окружение [ссылка на установку пакета из истории], команда запуска будет максимально простой и короткой:
bash
torchrun --nproc_per_node=1 NAFNet/basicsr/train.py -opt options/train/Tanahen/train_NAFNet_JPEG_4070Ti.yml --launcher pytorch
Используйте код с осторожностью.
Результаты этого обучения автоматически создадут новую независимую папку рядом с вашей текущей: NAFNet/experiments/NAFNet-JPEG-4070Ti/models/ [ссылка на пути результатов из истории].
