# Глава 3. Экспериментальная часть## 3.1. Методика проведения эксперимента и программный комплекс
Разработанный программный комплекс реализован на базе фреймворка PyTorch с использованием модифицированной архитектуры NAFNet. Процесс сквозного тестирования и обучения модели разделен на три последовательных этапа:

   1. Моделирование физической деградации (Генерация LQ-данных):
   Исходное RAW-изображение высокого разрешения ($4\times$) проходит стадию контролируемого зашумления и сжатия. Сначала применяется пространственное размытие (свёртка с гауссовской функцией рассеяния точки, PSF) и наложение аддитивного белого гауссовского шума (АБГШ). Затем выполняется оптический даунскейл в 2 раза, после чего происходит разделение кадра на субпиксельную сетку Байера (RGGB), что даёт дополнительное пространственное сжатие ещё в 2 раза. Суммарный фактор деградации равен 4.
   2. Формирование промежуточного контейнера:
   Зашумленные и сжатые данные упаковываются в виде четырёх независимых Bayer-каналов (RGGB). В качестве технического контейнера для хранения этих матриц используется несжатый формат TIFF. Это позволяет избежать потерь при квантовании и передавать геометрию кадра в нейросеть «как есть», без искажений.
   3. Обучение нейросетевой модели:
   Сформированные четырёхканальные LQ-изображения подаются на вход обёртки NAFNet, которая решает задачу совместного демозаикинга и супер-разрешения (Joint Demosaicing & 4x Super-Resolution), восстанавливая исходный эталон.

## 3.2. Конфигурация параметров деградации и зашумления
Параметры математической модели искажений зафиксированы в конфигурационном YAML-файле программного комплекса:

process_data:
  downscale_factor: 2              # Фактор предварительного оптического сжатия
  noise:
    add: true                      # Принудительное наложение шума (АБГШ)
    snr_db: 20                     # Опорное соотношение сигнал/шум (резервный параметр)
    correlated: true               # Включение коррелированной структуры шума
    psf_sigma: 0.5                 # Радиус размытия гауссовского фильтра (PSF)


* psf_sigma: 0.5 имитирует дифракционный предел реального объектива камеры при съёмке люпинов.
* Флаг correlated: true приближает характер распределения АБГШ к физическим шумам реальной кремниевой матрицы фотоприемника.

## 3.3. Параметры режима восстановления и функции потерь
Процесс минимизации ошибки и оптимизации весов сети настраивается через секцию обучения и комбинированный функционал потерь (CombinedLoss):

train:
  validation_freq: 1               # Частота запуска валидационного конвейера (в эпохах)
  save_checkpoint_epoch: 10        # Периодичность сохранения весов модели
  num_epochs: 1000                 # Оптимальная длительность мейл-рана (замена избыточным 5000)
  optim_g:
    type: AdamW                    # Оптимизатор с коррекцией весового распада
    lr: 1e-4                       # Базовая скорость обучения (старт)
    weight_decay: 1e-4             # Коэффициент регуляризации весов
    betas: [0.9, 0.999]            # Моменты оптимизатора
  scheduler:
    type: CosineAnnealingLR        # Косинусное сглаживание шага обучения
    T_max: 1000                    # Синхронизация периода шедулера с реальным числом эпох
    eta_min: 1e-7                  # Минимальный порог скорости обучения
losses:
  type: "combined"
  l1_weight: 1.0                   # Вес пространственной компоненты (L1-лосс)
  ffl_weight: 0.8                  # Повышенный вес для логарифмического спектрального лосса
  ffl_start_epoch: 100             # Эпоха подключения спектрального анализа (фаза прогрева графа)
  ffl_alpha: 1.5                   # Фокусирующий параметр Focal Frequency Loss
  ffl_log_factor: 100.0            # Масштабный множитель логарифма
  ffl_type: "log"                  # Использование модифицированного логарифмического лосса

Инженерные особенности настройки пайплайна:

* Синхронизация шедулера (T_max: 1000): Для снижения вычислительного стресса графа используется плавный косинусный алгоритм CosineAnnealingLR. Период полуволны жестко привязан к реальному числу эпох (1000), что гарантирует аккуратный вывод модели на плато сходимости.
* Двухфазный прогрев (ffl_start_epoch: 100): Первые 100 эпох сеть обучается исключительно на пространственном лоссе L1. Это необходимо для базовой настройки геометрии и весов входного оператора PixelShuffle(4). Начиная со 101-й эпохи, автоматически активируется логарифмический спектральный лосс ffl_type: "log" с весом 0.8. Он заставляет сеть подавлять АБГШ во всей полосе частот и ювелирно восстанавливать структуру мелких деталей лепестков и стеблей.
