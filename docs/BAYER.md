# Унификация массива Байера

Унификация массива Байера (Bayer Pattern Unification / BayerUnify) — это метод предварительной обработки в компьютерном зрении и вычислительной фотографии, который приводит сырые RAW-изображения с различными структурами фильтров (RGGB, BGGR, GRBG, GBRG) к единому стандартному формату.
Эта процедура критически важна при обучении современных нейросетей (например, для денойзинга, суперразрешения или демозаики), так как она позволяет обучать одну модель на разнородных датасетах от разных камер, не допуская смешивания цветовых каналов. [1, 2] 
------------------------------
## 📌 Зачем нужна унификация?
Матрица цифровой камеры покрыта мозаикой цветных фильтров (CFA). В зависимости от производителя и модели сенсора, считывание блока $2\times2$ пикселей может начинаться с разных цветов. Существует 4 базовых типа выравнивания: [3, 4, 5] 

   1. RGGB (Red, Green, Green, Blue)
   2. BGGR (Blue, Green, Green, Red)
   3. GRBG (Green, Red, Blue, Green)
   4. GBRG (Green, Blue, Red, Green)

Если подать эти данные в сверточную нейросеть (CNN) без изменений, модель перепутает каналы (например, примет красный цвет за синий). Обучать отдельную сеть под каждую камеру неэффективно, так как это дробит обучающую выборку. Унификация решает эту проблему. [6, 7] 
------------------------------
## 🛠 Основные методы унификации
Процесс перевода из одной структуры в другую опирается на геометрические трансформации, которые не должны нарушать пространственную структуру пикселей.
## 1. Метод кадрирования (Cropping) — для этапа обучения
Применяется при подготовке датасета. Чтобы изменить порядок пикселей в блоке $2\times2$, изображение сдвигают на 1 пиксель по горизонтали и/или вертикали путем отрезания (кроппинга) крайней строки или столбца. [6] 

* Плюс: Идеально сохраняет локальную структуру соседних пикселей.
* Минус: Изображение теряет 1 строку или 1 столбец на границах. [6] 

## 2. Метод дополнения (Padding) — для этапа инференса (тестирования)
Когда нейросеть уже работает на реальном устройстве, обрезать края у готовой фотографии нельзя. Для приведения к целевому шаблону изображение искусственно дополняют (падинг) на 1 пиксель с нужной стороны. После обработки нейросетью эти добавленные пиксели просто удаляются (де-унификация). [8] 
## 3. Отражение и транспонирование (Flip / Transpose)
В некоторых конфигурациях перевод паттерна осуществляют зеркальным отражением матрицы по вертикали/горизонтали или ее транспонированием, совмещенным с перестановкой каналов. [7] 
------------------------------
## 📊 Матрица переходов (Пример приведения к BGGR)
Чтобы превратить любой массив Байера в единый стандарт (например, в популярный формат BGGR), применяются следующие правила сдвигов:

| Исходный формат | Требуемый сдвиг для перевода в BGGR | Действие на границах |
|---|---|---|
| BGGR | Сдвиг не требуется (0, 0) | Оставить без изменений |
| RGGB | Сдвиг на 1 пиксель по диагонали (1, 1) | Отрезать/добавить 1 строку и 1 столбец |
| GRBG | Сдвиг на 1 пиксель по вертикали (1, 0) | Отрезать/добавить 1 строку |
| GBRG | Сдвиг на 1 пиксель по горизонтали (0, 1) | Отрезать/добавить 1 столбец |

------------------------------
## 🚀 Результат применения

* Увеличение выборки: Все доступные RAW-снимки из интернета объединяются в один гигантский тренировочный пул.
* Универсальность: Модель, обученная с применением BayerUnify, может быть развернута на любом смартфоне или камере, независимо от архитектуры сенсора (Sony, Omnivision, Samsung).
* Экономия ресурсов: Вместо поддержки четырех разных нейросетей разработчики обучают и оптимизируют только одну. [1, 2, 6]
